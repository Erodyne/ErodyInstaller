# ErodyInstaller

Installa i programmi di un PC nuovo dai siti ufficiali, tramite winget. Fa parte della **Erodyne Suite**.

- Programmi consigliati per categoria (browser, ufficio, multimedia, utilità, sicurezza, assistenza remota, componenti, giochi), con quelli già installati riconosciuti anche se installati senza winget.
- Ricerca nel catalogo di winget e del Microsoft Store.
- Profili: elenchi di programmi da riusare (predefiniti, creati da te, oppure quelli di MultiTool in `%ProgramData%\MultiTool\Profili`).
- Installa uno dopo l'altro in silenzio, con l'esito di ognuno; riprova da solo se winget si interrompe.

Si installa in Programmi (serve l'amministratore): dalla Erodyne Suite oppure aprendo `ErodyInstaller-Setup-<versione>.exe`. Comandi: `/S`, `--disinstalla [/S]`.

Richiede Windows 10/11 con winget ("Programma di installazione app" dal Microsoft Store).
